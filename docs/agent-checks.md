# 1-апта. Хрононың шешім ұсыну ережесі

Хроно `agentPolicy` арқылы ойынның ағымдағы күйін және миссия әрекеттерін оқиды. Кіріс — бюджет, ресурс, қанағаттану және әрекеттер. Шығыс — басымдық пен қолжетімді әрекет туралы ұсыныс.

1. Ресурс 65-тен төмен болса, ресурсқа басымдық беріледі.
2. Ресурс кемінде 65, ал қанағаттану 60-тан төмен болса, қанағаттануға басымдық беріледі.
3. Қалған жағдайда бюджет үнемделеді.
4. Агент бюджет жететін әрекеттердің ішінен таңдайды. Бюджет үнемдеу режимінде ең арзан әрекетті ұсынады.

Бірінші миссияда 20% бюджетке 10% және 20% тұратын әрекеттер қолжетімді. Ресурс 65%, қанағаттану 60% болса, Хроно 10% тұратын «Ескі бөлшекті тексеру» нұсқасын ұсынады. Егер бюджет 9% болса, ұсыныс берілмейді.

Репозиторий түбірінен `node agent_checks.js` командасын іске қосыңыз. Тест басымдық шектерін, әрекет құнына дәл тең бюджетті және бюджет жетпейтін жағдайды тексереді.

Шектеуі — Хрононың ұсынысы ағымдағы күй мен алдын ала берілген ережеге сүйенеді. Ойыншы стратегиялық әрекетті өзі таңдайды.

Тест пен осы түсіндірме Codex көмегімен дайындалды.
